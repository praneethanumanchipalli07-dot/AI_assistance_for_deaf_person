# AuraAssist AI 🧏

## AI Assistive Technology for Persons with Hearing Impairments

AuraAssist AI is an AI-powered web application designed to assist people with hearing impairments by converting speech and important environmental sounds into visual and haptic alerts.

### Features

- 📝 Real-time Live Captions
- 🔊 AI-based Sound Detection
- 🚨 Emergency Sound Alerts
- 👤 Name/Keyword Call Alerts
- 📳 Haptic/Vibration Feedback
- ⚙️ Customizable Alert Settings
- 🌐 IoT Integration Ready

### Technologies Used

- HTML
- CSS
- JavaScript
- Speech Recognition
- TensorFlow.js
- AI/Machine Learning

### Project Objective

To improve communication, environmental awareness, and safety for people with hearing impairments by making important audio information visible and actionable.

### Future Scope

- ESP32-based wearable device
- Smartwatch integration
- Advanced personalized sound detection
- Offline/Edge AI
- Multi-language captions
- IoT-based emergency alerts
